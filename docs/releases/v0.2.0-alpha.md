# Omadora v0.2.0-alpha

The second alpha includes the menu, package picker, desktop update and recording
fixes developed since v0.1.0-alpha, plus theme-colored application logos.
Target: **fresh Fedora Workstation 44, x86_64 (non-Atomic)**.

## Install

Run from GNOME as your regular Fedora user:

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.2.0-alpha/boot.sh | bash
```

Log out and choose **Omadora** in GDM after installation.

For existing installations, log out of Hyprland and run from GNOME or a TTY:

```bash
omadora upgrade --ref v0.2.0-alpha
```

Personal configuration is preserved; new defaults are not automatically merged.
The original alpha tag remains unchanged. This release's bootstrap and plain
desktop upgrade default to `v0.2.0-alpha`; explicit source overrides remain
available. Omarchy stays pinned to 4.0.4. Repository packages still follow their
configured repositories. See [quick start](https://github.com/DanielCoffey1/omadora/blob/v0.2.0-alpha/docs/QUICKSTART.md).

## Changes

- Install and Remove menus have consistent icons, including 67 bundled brand
  logos for 73 app entries. Logos follow the existing theme and selection colors.
- Fedora package installation searches the available package inventory; removal
  searches installed packages. Both support multiple selections.
- Web-app completion and optional-app terminals can be closed with Enter.
  The optional-app chooser is visible and its label fits the menu.
- Desktop updates refresh the Waybar indicator after the transaction and use
  a single terminal for the password prompt. Failed update queries preserve
  the previous indicator state.
- Fedora screen recording and related menu/bar actions have fixes and acceptance
  coverage, including saved silent, desktop-audio and microphone recordings.
- Dictation installs the missing Fedora library for its visualizer. Existing
  Dictation users may need `sudo dnf install gtk4-layer-shell`, followed by
  `systemctl --user restart voxtype.service` in their desktop session.
- The imported searchable **Super+K** keybindings guide is documented and
  protected by regression checks.

## Validation and limits

The functional revision `159ecb6` passed
[55 source checks and font reproducibility](https://github.com/DanielCoffey1/omadora/actions/runs/35415234412)
and [21 Fedora desktop checks](https://github.com/DanielCoffey1/omadora/actions/runs/35415235518).
The desktop run uses Fedora Cloud with the Workstation package environment.
Earlier update/menu fixes passed
[20 checks on a fresh official Workstation ISO installation](https://github.com/DanielCoffey1/omadora/actions/runs/35406094638).
These runs identify the revisions tested; this release changes version defaults
and documentation without additional desktop behavior changes.

This remains an alpha. The reported intermittent Windows-key failure was not
reproduced or confirmed fixed. Physical GPU, Bluetooth, multiple-monitor and
suspend coverage remains incomplete; QEMU/virtio suspend still fails. Optional
app mappings do not establish all account, gameplay or VM workloads. The update
password prompt was exercised, but a completed live DNF transaction followed by
indicator disappearance was not part of the desktop test. See the detailed
[validation record](https://github.com/DanielCoffey1/omadora/blob/v0.2.0-alpha/docs/VALIDATION.md)
and [compatibility notes](https://github.com/DanielCoffey1/omadora/blob/v0.2.0-alpha/docs/COMPATIBILITY.md).
