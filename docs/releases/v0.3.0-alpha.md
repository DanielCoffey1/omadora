# Omadora v0.3.0-alpha

Hardware-aware Fedora graphics setup, with gaming apps remaining optional.
Target: Fedora Workstation 44, x86_64, non-Atomic.

## Install or upgrade

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.3.0-alpha/boot.sh | bash
```

Existing users: log out of Hyprland and run from GNOME or a TTY:

```bash
omadora upgrade --ref v0.3.0-alpha
```

## Graphics

- Fresh installs detect PCI display controllers and ensure the AMD/Intel
  Mesa/Vulkan/firmware packages appropriate to the detected hardware. Virtual,
  unknown and vfio-owned devices are left alone.
- **Setup → Graphics** provides GPU status, gaming libraries and NVIDIA setup.
  Optional gaming setup adds 32-bit graphics libraries without installing games.
- `omadora gpu setup --nvidia --gaming`, run from GNOME/TTY, verifies all NVIDIA
  GPUs against the exact available driver's support list. It tries current and
  580xx packages; unsupported/ambiguous hardware stops rather than guessing.
- Secure Boot systems pause for MOK enrollment before NVIDIA installation.
  After enrollment, rerun setup. Module builds, signing and initramfs generation
  complete before a reboot is recommended; no automatic reboot is performed.
- `omadora gpu status` reports drivers and distinguishes hardware Vulkan from
  software/virtual rendering. `omadora gpu run -- application` enables per-app
  offload on supported hybrid configurations without global environment changes.

NVIDIA setup is explicitly requested, not installed silently on every machine.
This is an alpha setup flow, not certification of physical GPU/game compatibility.
GPU rendering, firmware enrollment, suspend, external displays and game workloads
still need testing on actual hardware. Existing driver providers/branches are
not silently replaced. Graphics package changes are outside desktop rollback.

See [graphics instructions and testing boundaries](../GRAPHICS.md), including
Steam launch options, legacy limitations and recovery. All previous fixes,
including the Super+K guide and prompt app-list refresh, are included.
