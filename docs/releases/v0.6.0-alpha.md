# Omadora v0.6.0-alpha

This release includes the changes made after v0.5.0-alpha:

- **Install → Gaming → NVIDIA drivers** starts the existing hardware-aware driver setup with 32-bit gaming libraries. Setup checks GPU support and Secure Boot, builds matching modules, and asks for a reboot. Driver installation remains an explicit action.
- Web-app launchers open URLs with the user's current default browser. Existing web apps use the new behavior after upgrading because their desktop entries call the shared launcher.
- The bar menu button uses a Fedora glyph from Omadora's Nerd Font and follows the bar's theme color.
- New bar configurations default to a 12-hour clock with AM/PM.
- The regular terminal shortcut starts Foot in the user's home directory.

The offline ISO includes these changes and passed the offline UEFI installation and first-desktop test in [run 35687217730](https://github.com/DanielCoffey1/omadora/actions/runs/35687217730). It uses the previously tested Fedora package inventory and installer runtime with the tagged v0.6.0-alpha desktop and all 332 wallpapers.

## Download the offline ISO

Download these four files from the assets below into the same folder:

- `Omadora-44-x86_64.iso.part1`
- `Omadora-44-x86_64.iso.part2`
- `Join-Omadora.cmd`
- `Join-Omadora.ps1`

**Windows:** double-click `Join-Omadora.cmd`. It creates
`Omadora-44-x86_64.iso` and verifies its SHA-256 checksum. Allow about 8 GB
of free space for the parts and completed image. An existing ISO is never overwritten.

**Linux/macOS:** download both parts and `Omadora-44-x86_64.iso.sha256`,
then combine them in a folder without an existing ISO:

```sh
(set -C; cat Omadora-44-x86_64.iso.part1 Omadora-44-x86_64.iso.part2 > Omadora-44-x86_64.iso)
# Linux:
sha256sum -c Omadora-44-x86_64.iso.sha256
# macOS:
shasum -a 256 -c Omadora-44-x86_64.iso.sha256
```

Only proceed if verification succeeds. Select the **completed .iso**, not either
part, in Fedora Media Writer and write it to an 8 GB or larger USB drive.
Writing the image erases that USB drive. Boot the USB and select Install Omadora.

GitHub limits each asset to under 2 GiB, so the ISO is distributed in two
parts. Joining them restores the exact tested ISO; no build is needed.

SHA-256: `082bf82c7f10947971def9f13655181c3bde1f5ba29e168df029d6e1c9759f8f`.

## Install from Fedora Workstation

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.6.0-alpha/boot.sh | bash
```

## Upgrade an existing Omadora installation

Log out of Hyprland and run from GNOME or a TTY:

```bash
omadora upgrade --ref v0.6.0-alpha
```

If the installed version lacks the upgrade command, use the new bootstrap with `bash -s -- upgrade` instead. The updater preserves personal bar configuration, so an existing 24-hour clock or a deliberately removed menu button stays as the user set it. To show the Fedora button in a personal layout, run `omarchy bar put omarchy.menu --before omarchy.workspaces` after upgrading.
