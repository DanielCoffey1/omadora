# v0.3.1-alpha

Fresh installations automatically detect managed NVIDIA GPUs and run verified
current/580xx driver setup, including matching 32-bit gaming libraries, before
deploying the Omadora desktop. Reboot after successful installation.

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.3.1-alpha/boot.sh | bash
```

Secure Boot enrollment still requires firmware approval. If prompted, enroll
the key during reboot and rerun the same installer command from GNOME or a TTY.
Unsupported hardware, conflicting driver providers and failed module builds stop
installation before desktop deployment. Existing installations keep explicit
GPU setup; upgrades do not automatically replace drivers.

See [graphics setup](../GRAPHICS.md) and the [previous release](v0.3.0-alpha.md).
Physical GPU rendering, firmware enrollment, suspend and gameplay remain unverified.
