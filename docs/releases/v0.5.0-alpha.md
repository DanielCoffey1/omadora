# v0.5.0-alpha

Release candidate: ISO installation acceptance is still in progress.

Adds an offline Omadora installer ISO using Fedora's graphical Anaconda
installer. Users select storage, encryption, timezone and account details,
then install and reboot into Omadora. The image includes Fedora hardware
support, the minimal desktop, GNOME fallback, pywal16 and all 332 wallpapers.
First-login setup applies Nepal automatically and preserves later user edits.
Bundled wallpaper data survives ordinary desktop runtime upgrades.

See [ISO instructions and validation](https://github.com/DanielCoffey1/omadora/blob/main/docs/ISO.md).
Hardware support uses Fedora's standard kernel/firmware packages; proprietary
NVIDIA drivers remain an explicit optional setup.

The existing Fedora Workstation installer is also available:

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.5.0-alpha/boot.sh | bash
```

Existing users can run `omadora upgrade --ref v0.5.0-alpha` from GNOME or a TTY
after this release is published. An ISO reinstall is not required for upgrades.
