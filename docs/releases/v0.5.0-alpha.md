# v0.5.0-alpha

Offline installer alpha. The complete offline UEFI installation and first-desktop
test passed at `0d230f9` in [run 35575539480](https://github.com/DanielCoffey1/omadora/actions/runs/35575539480).
A user also reported a successful installation on hardware; broader hardware testing remains needed.

Adds an offline Omadora installer ISO using Fedora's graphical Anaconda
installer. Users select storage, encryption, timezone and account details,
then install and reboot into Omadora. The image includes Fedora hardware
support, the minimal desktop, GNOME fallback, pywal16 and all 332 wallpapers.
First-login setup applies Nepal automatically and preserves later user edits.
Bundled wallpaper data survives ordinary desktop runtime upgrades.

## Download the offline ISO

Download these four files from the assets below into the same folder:

- `Omadora-44-x86_64.iso.part1`
- `Omadora-44-x86_64.iso.part2`
- `Join-Omadora.cmd`
- `Join-Omadora.ps1`

**Windows:** double-click `Join-Omadora.cmd`. It creates
`Omadora-44-x86_64.iso` and verifies its SHA-256 checksum. Allow about 8 GB
of free space for the parts and completed image. An existing ISO is never overwritten.

**Linux/macOS:** download both parts and `Omadora-44-x86_64.iso.sha256`,
then combine them in a folder without an existing ISO:

```sh
(set -C; cat Omadora-44-x86_64.iso.part1 Omadora-44-x86_64.iso.part2 > Omadora-44-x86_64.iso)
# Linux:
sha256sum -c Omadora-44-x86_64.iso.sha256
# macOS:
shasum -a 256 -c Omadora-44-x86_64.iso.sha256
```

Only proceed if verification succeeds. Select the **completed .iso**, not either
part, in Fedora Media Writer and write it to an 8 GB or larger USB drive.
Writing the image erases that USB drive. Boot the USB and select Install Omadora.

GitHub limits each asset to under 2 GiB, so the 3.9 GB ISO is distributed in two
parts. Joining them restores the exact tested ISO; no build is needed.

SHA-256: `9d503966771259684490fd22bd6eda5fc73d8b4f9e0dd6c81d03cc51709e3488`.

See [ISO instructions and validation](https://github.com/DanielCoffey1/omadora/blob/main/docs/ISO.md).
Hardware support uses Fedora's standard kernel/firmware packages; proprietary
NVIDIA drivers remain an explicit optional setup.

The existing Fedora Workstation installer is also available:

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.5.0-alpha/boot.sh | bash
```

Existing users can run `omadora upgrade --ref v0.5.0-alpha` from GNOME or a TTY
after this release is published. An ISO reinstall is not required for upgrades.
