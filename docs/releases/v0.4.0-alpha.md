# v0.4.0-alpha

Replaces the preset theme picker with a searchable wallpaper browser and pywal16
palettes. The supplied 332-wallpaper collection has bundled previews; full-size
images are downloaded and verified as selected. Nepal_5160x2160.png is included
and is the default on fresh installations.

Install → Style → Add wallpapers imports local images. Remove → Remove wallpapers
manages the library without deleting original imported files. Generated colors
feed the Omadora shell and existing application templates, GTK and Qt6ct. Some
applications need reopening; sandboxed or independently themed apps may not follow.
See [wallpaper behavior and coverage](https://github.com/DanielCoffey1/omadora/blob/main/docs/WALLPAPERS.md).

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.4.0-alpha/boot.sh | bash
```

Existing users can run `omadora upgrade --ref v0.4.0-alpha` from GNOME or a TTY,
then select a wallpaper in the new browser. Existing themes remain until that
selection. NVIDIA driver setup stays manual; this release does not repair or
remove graphics drivers already installed on a machine.

Validation: 77 source checks, Fedora installation/upgrade/recovery, and a booted
Fedora desktop test of preview selection, palette changes, native import and
confirmed removal all pass. See the [validation record](https://github.com/DanielCoffey1/omadora/blob/main/docs/VALIDATION.md)
for evidence and the remaining intermittent GDM session-start limitation.
