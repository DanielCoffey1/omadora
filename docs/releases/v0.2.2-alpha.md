# Omadora v0.2.2-alpha

Fix the interactive keybindings guide used by **Super+K** and
**Omadora menu → Learn → Keybindings**. The upstream selector serialized its
popup request using Perl's JSON::PP module, which the minimal Fedora manifest
did not install. The selector and text-input helpers now use Python's standard
JSON library, already required by Omadora. Existing layout, themes, filtering,
binding dispatch and personal shortcuts are preserved.

Includes v0.2.1-alpha's application-list refresh and all earlier fixes.
Target: Fedora Workstation 44, x86_64, non-Atomic.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.2.2-alpha/boot.sh | bash
```

Existing users: log out of Hyprland and run from GNOME or a TTY:

```bash
omadora upgrade --ref v0.2.2-alpha
```

No personal binding or theme reset is required. The guide still reads the live
Hyprland bindings and imported Lua configuration.

## Regression coverage

Linux source checks execute both generated popup helpers with Perl disabled,
covering Unicode/quoted options, dimensions, selection, cancellation and
temporary-file cleanup. The dedicated Fedora desktop test opens the actual
guide using Super+K and the Learn menu, filters for Terminal, activates that
binding from both routes, and checks Escape cancellation. Earlier tests only
verified the entry-point wiring and printed binding list; they did not cover
opening this popup. Exact run results are in the release's GitHub notes and
[validation record](../VALIDATION.md).

Existing alpha hardware and application-workload limitations remain unchanged.
