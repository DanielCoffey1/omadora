# v0.3.2-alpha

Reverts automatic NVIDIA driver installation introduced in v0.3.1-alpha after
a G14 laptop report of severe display lag and login failure. The root cause
has not been established. Fresh installations no longer invoke NVIDIA setup,
enable RPM Fusion for it, install NVIDIA packages, or request MOK enrollment.
AMD/Intel base graphics packages, GPU diagnostics, and explicit manual NVIDIA
setup remain available.

```bash
curl -fsSL https://raw.githubusercontent.com/DanielCoffey1/omadora/v0.3.2-alpha/boot.sh | bash
```

This is an installer rollback, not a driver uninstaller. Updating Omadora or
using omadora rollback does not remove drivers already installed on an affected
machine. That machine needs separate Fedora package recovery; we have no direct
access to the reported laptop and have not repaired or diagnosed it yet.

Old release tags remain unchanged. Use v0.3.2-alpha for new installations.
