# Bundled font

`OmadoraAppIcons.ttf` is the small, theme-colored application logo font. Its
source artwork, attribution, mappings and reproducible build instructions are
in [../icons/README.md](../icons/README.md). It is separate from the text font
below and is loaded directly by the menu on both installations and upgrades.

JetBrainsMonoNL Nerd Font Regular from Nerd Fonts v3.4.0, commit `fa7b859994228a9c8759f99c55a8d31ee92a1b5e`.

Source: https://github.com/ryanoasis/nerd-fonts/tree/fa7b859994228a9c8759f99c55a8d31ee92a1b5e/patched-fonts/JetBrainsMono/NoLigatures/Regular

SHA-256: `efd0c812226247ba45bb31a816ec63876fb0d8d930dbb0e633770965fcc81081`.

Redistributed under the adjacent OFL.txt. The font supplies the desktop's Nerd Font glyphs without installing a large font collection.
